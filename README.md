# 🌟 Introduction

WhatsStats is an intelligent WhatsApp chat analytics platform that transforms raw exported chat data into meaningful insights, interactive visualizations, and communication statistics.

The system leverages:
- **Data Analysis**
- **Natural Language Processing**
- **Regex-based Text Parsing**
- **Interactive Visualization**
- **Statistical Analytics**

to analyze user conversations and uncover communication patterns.

This project demonstrates:
- Data Cleaning Pipelines
- NLP-based Text Processing
- Chat Analytics
- Visualization Dashboards
- Streamlit Application Development

---

# 🎯 Problem Statement

Raw WhatsApp chat exports are:
- Unstructured
- Difficult to analyze manually
- Hard to visualize meaningfully
- Time-consuming for extracting insights

WhatsStats solves this by:
✅ Automating chat preprocessing  
✅ Generating visual analytics  
✅ Identifying user activity patterns  
✅ Extracting meaningful conversation insights

# 🚀 Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/vamsimeenan/whatsstat.git
```

---

## 2️⃣ Navigate to Project

```bash
cd whatsstat
```

---

## 3️⃣ Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5️⃣ Run Application

```bash
streamlit run app.py
```

or

```bash
python app.py
```
