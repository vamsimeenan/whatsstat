## 📌 Project Overview
WhatsStats is a Python-based data analysis tool that helps you analyze WhatsApp chat exports and extract meaningful insights from conversations.

It converts raw chat data into visual analytics like:

- 📈 Message activity trends  
- 👥 Most active users  
- 📝 Word frequency analysis  
- ⏰ Hourly & daily activity patterns  
- 🔥 Interactive chat statistics
